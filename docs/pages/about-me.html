About Me

Hello! My name is Brian Estevez. I really enjoy using and learning about Python programming, UAV or Drone technology, and Geographical Information Systems (GIS).

This site is a place to share in the exploration of these topics.

Key GIS projects:

  • UAV Asset Mapping – Used drone imagery and Pix4DMatic , ArcGIS Pro to map assets (road lines, parking stalls, manholes, drains)

  • Groundwater Contamination Dashboard – Integrated state well data with ArcGIS Pro and Python Link

  • Custom ArcPy Tools – Developed scripts and workflows for automating geoprocessing Link

  • Disaster Damage Assessment – Applied ArcGIS Deep Learning for hurricane damage mapping Link and online map here: AGOL
